# Agent Context Policy

Future coding sessions load `AGENTS.md`, `PROJECT_STATUS.md`, relevant REQ rows, one architecture document/ADR/skill, then targeted code/tests. They do not reread all sources or the master plan unless resolving provenance, scope, or architecture ambiguity.

Durable outcomes belong in repository docs; chat history is disposable.

Client source documents and full chat exports are local-only under the ignored `docs/product/source-requirements/` path. Normalized requirements and sanitized repository documentation are the Git development source.
