# Incident Response

1. Preserve evidence and identify organization/data class affected.
2. Contain access or failing integration without deleting records.
3. Rotate exposed credentials through the documented key process.
4. Assess client/legal notification obligations with the owner.
5. Recover from verified revision/backup and validate isolation.
6. Add regression tests and record implementation/architecture/requirement changes in the correct logs.

Never paste secrets or raw medical data into tickets or chat.
